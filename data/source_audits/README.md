# カミキリムシ文献監査台帳

`japanese-longhorn-beetles-2007.csv` は、大林延夫・新里達也編（2007）
『日本産カミキリムシ』の種解説をPDF原本で目視確認した監査台帳です。

- `include`: 対象種・亜種と原典記述の対応を確認し、食草・出現期・生態を掲載する。
- `include_shared_group`: 原典刊行後の亜種分割をまたぐ種共通値を、包含されていた現行分類群へ共有する。
- `exclude_not_in_source`: 原典刊行後に記載された分類群など、同原典の情報を適用しない。
- `merge_duplicate_taxon`: 旧分類名と受容名が別行になっていた重複を受容名へ統合する。
- `needs_review`: 対応関係を確定できず、自動適用しない。

PDFとOCRのSHA-256、PDFページ、冊子ページ、確認日を各行に保持しています。
OCRは候補箇所の探索だけに使い、掲載値はPDF原本の目視結果を採用します。
類似名の自動照合は行いません。
原典の種解説と紐付けられたまま食草・出現期・生態がどれも未反映だった
176分類群を採用し、現在の厳密照合範囲で「食草も生態も未入力」の対応候補は0件です。

`japanese-longhorn-beetles-2007-host-index.csv` は、同書の寄主植物一覧
（PDF 175–220ページ、冊子683–773ページ）をPDF原本で全ページ目視した監査台帳です。
登録和名・登録別名の完全一致、種解説で確認済みの対応、および亜種名を省略した
597候補を対象としています。省略和名は寄主索引画像だけで決めず、種解説の学名・亜種見出しと
現行の同種群を再照合し、名義亜種へ直接帰属できる場合だけ採用します。

- `include`: 植物見出しと掲載和名を原典画像で確認し、植物名・科を現行データへ正規化して掲載する。
- `exclude_ocr_or_boundary`: OCRの植物境界誤認、または訂正後に既存レコードと重複するため追加しない。
- `needs_review`: 原典自体に疑問符があり、確実な寄主記録としては掲載しない。

各行はPDFページ、冊子ページ、OCR行、原典名、現行ID、目視判断を保持します。
1,895候補のうち1,650組を採用し、101組を除外、144組を保留しています。
保留のうち138組は、原典刊行後の亜種分割により、産地のない索引記録を現行の基亜種へ
一意に配分できなかったものです。原台帳の判断履歴は変更せず、再検討結果を
`japanese-longhorn-beetles-2007-shared-host-index.csv` に分離して保存します。

共有台帳では、原典が亜種を限定しない108件を `species_level_shared` とし、現行の全亜種へ
394寄主行を共有します。学名で名義亜種を明記する30件は
`historical_subspecies_concept_shared` とし、2007年時点の名義亜種概念に含まれていた
後年分離亜種だけへ60寄主行を共有します。小笠原・八重山など当時の概念外にある59候補は
過大な共有として除外します。疑問符付き6件は元台帳の `needs_review` のまま公開しません。
共有台帳は元の `audit_id`、PDF/OCRハッシュ、PDF・冊子ページ、OCR行、共有先ID、除外先ID、
生成する `record_id` を保持し、454寄主行を同じIDで再生成します。

## 日本産タマムシ大図鑑の原本監査（2026-07-11）

`japanese-jewel-beetles-grand-atlas-audit-2026-07-11.json` は、PDF原本と
探索用OCRのSHA-256、ページ対応、集計値、適用上のガードレールを保持します。
同名のCSV群には、既存注記211分類群の種解説ページ、寄主欄が不明だった50分類群、
原典刊行後の分類変更に関する34群のsource scope、タマムシへ誤集約された69寄主行、
12組の重複生態行、および実際に適用する129件の高確度修正を分けて記録しています。
番号付き219種解説との照合では、丸ごと未抽出だった5解説をすべて回収し、現行亜種への
共有を含めて文献由来の注記がある分類群は222分類群になりました。番号外の
キタニセナガタマムシ解説も同時に回収しています。

寄主欄が「不明」の場合、植物上での採集・飛来だけを幼虫寄主へ昇格しません。
ヤエヤマムナビロタマムシでは成虫がタイワンウオクサギの生葉を後食することが
原本に明記されるため、`observation_type=後食`、`life_stage=成虫` として登録し、
幼虫寄主ではないことを注記します。リュウキュウナガタマムシのリュウキュウエノキと
コーヨーナガタマムシのヤチダモは、同様に `observation_type=採集植物`、`life_stage=成虫`
として幼虫寄主と分けます。分割後の現行分類群IDが未収載の23群は、
scopeを台帳化するだけにとどめ、自動複製をfail closedで保留します。
原文に併記された異名判断、移動要因の仮説、献名説明は監査証拠に保持しますが、
公開生態情報には時期・分布・摂食・採集・形態の客観文だけを残します。
最終整合監査では公開一般注記400行を全走査し、原PDFの該当種解説を300 dpi画像で再確認した上で、
推論6行、献名説明14行、異名判断3行の計23行を客観文だけへ置換しました。希少・局所的・少ない
などの観察頻度、採集個体数、分布、食害、形態差は削除していません。実適用CSV全体のSHA-256も
適用処理で固定し、同件数の別台帳への差し替えを拒否します。

正規化CSVへの反映は次のコマンドで再現できます。

```sh

npm run repair:literature-record-integrity
```

適用処理は監査ID、原本ハッシュ・ページ、対象昆虫、変更前値を検証し、
削除・本文修正・関係メタデータ更新・成虫後食記録の追加を冪等に行います。
一般注記は本文と出典で照合するため、後段のID再計算後も同じ台帳を安全に再適用できます。
