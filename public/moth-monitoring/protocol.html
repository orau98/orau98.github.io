Protocol

2026年度 トラップ構造比較プロトコル

今年度は、標準ライトトラップを決める前段階として、光源を10W級ブラックライトに固定し、トラップの構造や捕獲部の違いが、飛来から残留までの過程にどのような影響を与えるかを比較します。最終的な残留数だけでなく、飛来、接触、進入、逃出、残留、同定までを分けて記録し、どの段階で構造差が生じるのかを明らかにします。

今年度は光源比較ではなく、トラップ構造の比較に焦点を当てます。光源、点灯時間、設置条件、観察時刻をできるだけそろえたうえで、構造や捕獲部の違いが記録数と記録過程に与える影響を検証します。

実験の基本方針

Structure

構造差を見る

光源は10W級ブラックライトに固定し、トラップの構造、捕獲部への導線、逃げにくさなどを比較します。

Control

条件をそろえる

地点、点灯時間、光源の向き、設置高さ、観察間隔をできるだけ統一し、構造以外の要因で差が出にくいようにします。

Process

過程を分けて記録する

最終的な残留数だけでなく、飛来、接触、進入、逃出、残留、同定を分けて記録し、構造差がどの段階で生じるかを見ます。

記録過程の定義

この試験では、最終的な残留数だけでなく、蛾がトラップに記録されるまでの過程を分けて記録します。記録過程は、飛来、接触、進入、逃出、残留、同定の6段階に分けます。

飛来 → 接触 → 進入 → 逃出 → 残留 → 同定

飛来、接触、進入、逃出は、観察時間中に見られた行動イベントとして記録します。同じ個体が複数回飛来・接触する可能性があるため、これらは厳密な個体数ではなく、観察イベント数として扱います。残留と同定は、回収時に残っていた個体と、その後の写真・標本確認に基づいて記録します。

各段階の定義

段階記録するもの定義数え方注意点
飛来観察イベント光源またはトラップ周辺の観察範囲に個体が入ること。観察窓ごとに、観察範囲に入ったイベント数を数える。同じ個体が一度観察範囲を離れ、再び入った場合は別イベントとして扱います。観察範囲の目安は光源またはトラップ周辺50cm程度とし、現場条件で変える場合は記録します。
接触観察イベント飛来した個体が、入口部、衝突板、漏斗、誘導部、トラップ外面など、トラップ本体に触れる、または着地すること。観察窓ごとに、トラップ本体への接触イベント数を数える。光源だけへの接触は、原則として接触に含めません。必要な場合は備考または任意項目として記録します。
進入観察イベント個体の全身が、あらかじめ決めた進入境界を越えて捕獲部内に入ること。観察窓ごとに、捕獲部内へ入ったイベント数を数える。漏斗や誘導部に触れただけでは進入としません。トラップ構造ごとに、どこを進入境界とするかを図または説明で明示します。
逃出観察イベント進入後の個体が、捕獲部の外へ出ること。観察窓ごとに、捕獲部外へ出たイベント数を数える。見失っただけの場合は逃出とせず、備考に記録します。明確に外へ出た場合のみ逃出として数えます。
残留回収個体消灯・回収時点で、捕獲部内に残っている個体。回収時に残っていた個体数を数える。生存、死亡、損傷、逃出の疑いを分けて記録します。残留数は観察イベントではなく、回収時の個体数として扱います。
同定確認済み記録写真または標本に基づき、種名、属、種群など、解析に使える分類単位まで確認すること。同定レベル、同定者、確度、未同定理由を記録する。難種は無理に種名まで落とさず、属、種群、未同定として扱います。希少種や公開に配慮が必要な記録は公開範囲を分けます。

観察イベントと回収個体を分けて扱います

飛来、接触、進入、逃出は、観察中に見られた行動イベントです。同じ個体が複数回カウントされる可能性があります。一方、残留は回収時に捕獲部内に残っていた個体数です。この2つを混同しないことで、記録数が少なかった理由を、蛾が来なかったのか、接触したが入らなかったのか、入ったが逃げたのか、回収時まで残らなかったのかに分けて考えられます。

今年度に比較するもの

この試験では、光源を変えて蛾を多く集める方法を探すのではなく、同じ光源を使ったときに、どのトラップ構造が安定して記録しやすいかを比較します。

変える条件

  • トラップの構造
  • 衝突板の有無・形状
  • 捕獲部への入りやすさ
  • 逃げ出しにくさ
  • 観察・回収のしやすさ

そろえる条件

  • 光源：10W級ブラックライト
  • 点灯時間
  • 設置高さ
  • 光源の向き
  • 入口までの距離
  • 調査地点
  • 観察間隔
  • 記録者ID
  • 回収時刻
  • 写真・標本の扱い

光源の向きや設置位置が構造ごとに変わると、構造差ではなく光源条件の差を見てしまう可能性があります。そのため、光源の向き、高さ、入口までの距離は、両構造でできるだけ共通化します。共通化できない点は、記録項目として残します。

構造比較試験の流れ

  1. 調査前準備: 調査許可、地点ID、トラップID、電源、予備機材、天候見込み、日没時刻、観察担当者を確認します。
  2. トラップ設置: 比較するトラップを同じ地点内に配置します。設置高さ、光源の向き、入口までの距離、周辺植生、トラップ間距離を記録します。
  3. 点灯開始: 点灯時刻、光源仕様、電源状態、気温、風、雲量、降雨、月齢を記録します。光源は原則として10W級ブラックライトに統一します。
  4. リアルタイム観察: 一定間隔で、飛来、接触、進入、逃出を記録します。観察者がいる場合は観察者IDも残します。
  5. 回収: 消灯・回収時刻、残留個体数、欠測、機材トラブル、採集物の保存方法を記録します。
  6. 同定: 写真、標本、同定者、同定レベル、確度、未同定理由を記録します。難種や未同定個体は無理に種名まで落とさず、扱いを明示します。
  7. データ整理: 調査イベント、トラップ条件、観察イベント、同定結果を分けて整理し、公開可否と希少種情報の扱いを確認してから集計します。

調査時間の標準化

トラップ構造を比較するためには、調査時間をできるだけそろえる必要があります。蛾の活動は時計時刻そのものよりも、日没からの経過時間に強く関係するため、このプロトコルでは日没を基準に調査時間を決めます。

標準調査

標準調査は、日没後30分以内に点灯開始し、3時間後に消灯・回収することを基本とします。夏場はおおむね19:00〜22:00、日没が早い時期は18:00〜21:00が目安です。

時期目安の時間扱い
夏場19:00〜22:00標準3時間調査
日没が早い時期18:00〜21:00標準3時間調査
さらに日没が早い時期日没後30分以内〜3時間標準3時間調査。実際の点灯・消灯時刻を記録する

延長調査

日没が早い時期に18:00〜22:00のように4時間実施する場合は、標準3時間を超える延長調査として扱います。延長調査は実施してよいですが、主解析では原則として最初の3時間を使い、延長分は補助解析または運用確認として扱います。

実施時間扱い解析での扱い
19:00〜22:00標準調査主解析に使用
18:00〜21:00標準調査主解析に使用
18:00〜22:00延長調査を含む主解析では最初の3時間を使用。21:00〜22:00は延長分として別扱い
2時間未満短時間調査原則として主解析から外し、補助データとして扱う

A型での時間ルール

A型の同日ペア比較では、比較する2つの構造で点灯時刻、消灯時刻、観察窓をそろえます。片方のトラップだけ早く停止した場合、その時点以降はペア比較として扱いません。

B型での時間ルール

B型の同一地点クロスオーバー比較では、同じ地点で毎回できるだけ同じ標準時間を使います。ある構造だけ4時間、別の構造だけ3時間になると、構造差と調査時間差が混ざるため避けます。やむを得ず調査時間が異なる場合は、effort_hours として実際の調査時間を記録し、解析時に補正します。

観察窓の推奨ルール

飛来、接触、進入、逃出を連続して観察し続けるのは、市民科学では負担が大きくなります。そのため、標準調査では短い観察窓を決め、観察努力量を記録します。

標準観察窓は、点灯後30分、60分、90分、120分を目安に、それぞれ5分間とします。

観察窓目安記録するもの
1回目点灯後30分から5分間飛来、接触、進入、逃出
2回目点灯後60分から5分間飛来、接触、進入、逃出
3回目点灯後90分から5分間飛来、接触、進入、逃出
4回目点灯後120分から5分間飛来、接触、進入、逃出

人手に余裕がある場合は観察窓を増やしてもよいですが、観察開始時刻、観察終了時刻、観察分数、観察者IDを必ず記録します。人手が少ない場合は、観察窓を減らしても構いませんが、最終残留数、点灯時刻、消灯時刻、構造、光源、地点、天候は必ず記録します。

比較条件

区分今年度の扱い注意点
光源10W級ブラックライトに固定光源比較は今年度の主目的にしません。型番、波長表記、電圧、電流、ライトIDは記録します。
構造比較対象谷型、漏斗型、衝突板付き構造など、構造差が記録過程に与える影響を見ます。
光源の向き原則として共通化構造ごとに光源の縦横や向きが変わると交絡するため、できるだけ同じ向き・高さ・距離にします。共通化できない場合は記録します。
調査時間日没基準の標準3時間調査夏場は19:00〜22:00、日没が早い時期は18:00〜21:00を目安にします。18:00〜22:00のような4時間調査は延長調査として分けます。
設置位置同一地点内で比較微環境差を避けるため、位置を固定せず、日や地点でローテーションできる設計にします。
観察方法人によるリアルタイム記録飛来、接触、進入、逃出を同じ時間幅で記録します。観察者IDを残します。
回収方法同じ時刻・同じ手順で回収残留数、死亡・損傷、逃出、保存状態を記録します。
反復複数日・複数地点で確保短期の試作ではなく、日差・地点差を含めて構造差を評価します。

構造差を見るための評価指標

この試験では、最終的な残留数だけを比較しません。どの構造が、どの段階で差を生むのかを分けて見ます。

飛来イベント率飛来イベント数 / 観察分数。観察努力量をそろえて比較します。
接触率接触イベント数 / 飛来イベント数。トラップ本体へ近づいた後の反応を見ます。
進入率進入イベント数 / 接触イベント数。接触後に捕獲部へ入った割合です。
逃出率逃出イベント数 / 進入イベント数。捕獲部の構造や逃げにくさの評価に使います。
残留数回収時に捕獲部内に残っていた個体数。観察イベントではなく回収個体です。
残留率・残留効率残留数 / 進入イベント数。ただし、観察イベントと回収個体の対応が完全ではないため補助指標として扱います。
同定率記録された個体のうち、種名または扱える分類単位まで確認できた割合です。

記録数 ≒ 飛来イベント数 × 接触率 × 進入率 × 残留率 × 同定率

飛来、接触、進入、逃出は観察イベント数であり、残留は回収時の個体数です。そのため、この式は厳密な個体追跡式ではなく、記録過程を理解するための概念式です。解析では、観察イベントに基づく指標と、回収個体に基づく指標を分けて扱います。

この分解により、あるトラップで記録数が少なかったときに、蛾が来なかったのか、接触したが入らなかったのか、入っても逃げたのか、同定できなかったのかを区別できます。

野外チェックリスト

持ち出し前

  • 10W級ブラックライト
  • 電源・予備バッテリー
  • 比較対象のトラップ本体
  • 入口部品・衝突板・捕獲容器
  • 記録過程の定義表を持ったか
  • 観察窓の時刻を確認したか
  • 当日の日没時刻を確認したか
  • トラップIDラベル
  • メジャーまたは距離確認用具
  • 記録シートまたは記録フォーム
  • 撮影機材
  • 採集許可・緊急連絡先

設置時

  • 光源の向き・高さをそろえたか
  • 入口までの距離を記録したか
  • 点灯開始時刻を記録したか
  • 日没から点灯までの分数を記録したか
  • 標準3時間調査か延長調査かを決めたか
  • トラップ間距離を記録したか
  • 周辺植生・人工光を記録したか
  • トラップIDと位置を対応させたか

観察中

  • 観察時刻をそろえたか
  • 飛来、接触、進入、逃出の定義を共有したか
  • 飛来・接触・進入・逃出を分けて記録したか
  • 観察開始・終了時刻を記録したか
  • 観察分数と観察者IDを記録したか
  • 天候変化や機材トラブルを記録したか

回収後

  • 残留数を記録したか
  • 消灯時刻と回収時刻を記録したか
  • 残留数を観察イベントと混同せずに記録したか
  • 標準3時間を超えた延長分を分けて扱ったか
  • 死亡・損傷・逃出の可能性を記録したか
  • 写真・標本番号を対応させたか
  • 未同定個体の保管方法を決めたか
  • 公開不可情報を分けたか
