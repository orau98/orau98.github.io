A型/B型を選ぶ

今年度の目的

今年度は、全国モニタリングを始める前の準備段階です。目的は、長期的に使える標準トラップを決めるために、トラップ構造の違いが記録過程に与える影響を調べることです。

変えるもの

トラップ構造。入口部、衝突板、漏斗、捕獲部、逃げにくさ、観察・回収のしやすさを比べます。

そろえるもの

光源、点灯時間、設置条件、観察窓、記録項目をできるだけそろえます。光源は原則として10W級ブラックライトに固定します。

まず選ぶ：A型かB型か

市民科学では、参加できる人数や機材が地点ごとに異なります。このプロトコルでは、2つの実験型を用意します。大事なのは、全国の別々の場所を単純に比べることではなく、同じ地点の中で構造を比べることです。

あなたはどれ？

A型 2台を同時に置ける 同日ペア比較。同じ日・同じ地点で2構造を同時に比べます。最も強い比較データです。
B型 1台ずつなら置ける 同一地点クロスオーバー比較。同じ地点で日を変えて構造を入れ替えます。解析に使える比較データです。
補助 1構造だけ・単発で参加 補助記録。季節記録、分布記録、運用確認として残します。構造比較の主解析には使いません。

実験型の選び方

実験型どんな人向けかやることデータの強さ
A型：同日ペア比較2台を同時に設置できる人・チーム同じ日・同じ地点で2構造を同時に比べる最も強い比較データ
B型：同一地点クロスオーバー比較1台ずつなら設置できる人同じ地点で日を変えて構造を入れ替える解析に使える比較データ
補助記録1構造だけ、または単発で参加する人季節記録、分布記録、運用確認として記録する構造比較の主解析には使わない

A型とB型は、どちらも同じ地点の中で構造を比べる方法です。場所ごとに異なる構造を使った記録を単純に比べることはしません。

A型：同日ペア比較

同じ日・同じ地点で、2つのトラップ構造を同時に設置します。日付、天候、季節の影響をそろえやすいため、構造差を最も見やすい方法です。

  1. 同じ地点内にP1、P2の2位置を決める
  2. どちらの構造をどちらに置くかランダムに決める
  3. 光源、点灯時間、観察窓をそろえる
  4. 次回はできるだけ位置を入れ替える

B型：同一地点クロスオーバー比較

1台ずつしか設置できない場合は、同じ地点で日を変えて構造を入れ替えます。日付や天候の差が混ざりやすいため、気温、風、月齢、調査時間を必ず記録します。

  1. 同じ地点で調査を続ける
  2. 構造Aと構造Bを決められた順序で使う
  3. 最低でも各構造2有効夜ずつ行う
  4. できれば各構造3〜4有効夜ずつ行う

推奨配列

配列実施順使いどころ
ABBAA → B → B → A標準的な配列
BAABB → A → A → BABBAと組み合わせる
ABAB / BABA交互に入れ替える短期間で繰り返す場合

当日の基本フロー

当日は、実験型を選び、条件をそろえ、観察窓で記録し、回収後に同定できる形で整理します。

  1. 実験型を選ぶ: A型かB型かを決めます。A型では pair_id、B型では crossover_sequence を記録します。
  2. 設置する: 地点ID、位置ID、トラップID、光源IDを記録します。光源の高さ、向き、入口までの距離をそろえます。
  3. 点灯する: 日没時刻、点灯時刻、気温、風、雲量、降雨、月齢を記録します。
  4. 観察する: 観察窓ごとに、飛来、接触、進入、逃出を記録します。
  5. 回収する: 消灯時刻、回収時刻、残留数、死亡・損傷、機材トラブルを記録します。
  6. 同定する: 写真または標本に基づき、種名、属、種群、未同定などを記録します。
  7. 提出する: 記録フォームに入力し、写真・標本番号・公開可否を対応させます。

記録過程の定義

この試験では、最終的な残留数だけでなく、どの段階で差が出たかを分けて見ます。

飛来 → 接触 → 進入 → 逃出 → 残留 → 同定

各段階の数え方

段階数えるもの定義注意点
飛来観察イベント光源またはトラップ中心から半径1 m以内に入ったイベント半径2 m以内の接近は任意項目として記録できます。偶然通過と完全には分けられないため、標準範囲を決めて数えます。
接触観察イベント光源、入口部、衝突板、漏斗、誘導部、トラップ外面などに触れる、または着地すること接触先を、光源、入口部、衝突板、漏斗・誘導部、外面、不明に分けて記録します。
進入観察イベント個体の全身が、決められた進入境界を越えて捕獲部に入ること進入境界は構造ごとに図や説明で確認します。
逃出観察イベント進入後の個体が捕獲部の外へ出ること見失っただけでは逃出にしません。明確に外へ出た場合のみ数えます。
残留回収個体回収時点で捕獲部に残っていた個体生存、死亡、損傷、逃出疑いを分けて記録します。
同定確認済み記録写真または標本で、種名、属、種群などに確認すること難種は無理に種名まで落とさず、同定レベルと確度を記録します。

飛来、接触、進入、逃出は観察イベントです。同じ個体が複数回数えられる可能性があります。残留は回収時の個体数です。この2つを混同しないようにします。

調査時間と観察窓

構造差を見るには、調査時間と観察努力量をそろえる必要があります。時計時刻だけでなく、日没からの経過時間を記録します。

標準調査

日没後30分以内に点灯し、3時間後に消灯・回収します。夏場は19:00〜22:00、日没が早い時期は18:00〜21:00が目安です。

延長調査

18:00〜22:00のように4時間行う場合は、最初の3時間を標準調査、残りを延長分として扱います。主解析では原則として標準3時間を使います。

観察窓

点灯後30分、60分、90分、120分を目安に、それぞれ5分間観察します。人手が少ない場合は観察窓を減らしてもよいですが、観察分数を必ず記録します。

標準時間の扱い

実施時間扱い解析での扱い
19:00〜22:00標準3時間調査主解析に使用
18:00〜21:00標準3時間調査主解析に使用
18:00〜22:00延長調査を含む最初の3時間を主解析、延長分は補助扱い
2時間未満短時間調査原則として補助データ

A型では、2つの構造で点灯時刻、消灯時刻、観察窓をそろえます。B型では、同じ地点で毎回できるだけ同じ標準時間を使います。調査時間が異なる場合は effort_hours と observation_minutes を必ず記録します。

最低限、以下がそろっていれば、構造比較のデータとして扱いやすくなります。

必須項目

区分記録する項目なぜ必要か

変える条件とそろえる条件

区分今年度の扱い注意点
トラップ構造比較する入口部、衝突板、漏斗、捕獲部、逃げにくさを含めて評価します。

よくあるミス

場所差と構造差を混ぜる

別々の場所で違う構造を使って単純比較すると、構造比較には使いにくくなります。

片方だけ長く点灯する

調査時間差が記録数に影響します。effort_hours を必ず記録します。

イベントを個体数として扱う

飛来、接触、進入、逃出は観察イベントです。同じ個体が複数回数えられる可能性があります。

接触先を記録しない

光源に触れたのか、トラップ本体に触れたのかで意味が変わります。

無理に種名まで落とす

同定できない個体は、属、種群、未同定として扱い、同定レベルと確度を残します。

論文化を見据えた目標

論文化では、個体数そのものより、比較可能な地点数、有効トラップナイト、A型ペア比較、B型クロスオーバー地点が重要です。

今年度の反復数目標

目標比較可能な地点数有効トラップナイトA型ペア比較B型クロスオーバー地点
最低ライン10〜15地点100以上30ペア以上10地点以上
標準目標20〜30地点200〜30050〜80ペア15〜25地点
理想目標30地点以上300〜50080〜100ペア20〜25地点以上

同じ地点・同じ夜に多くの個体が得られても、それだけで独立したサンプルが増えたとは考えません。地点と日をまたいだ反復を増やすことを重視します。

A型とB型の解析上の扱い

A型とB型は統合解析できます。ただし、単純に混ぜるのではなく、experiment_type または data_rank として区別して扱います。まずA型、B型を別々に確認し、同じ方向の構造差が見られるかを確認したうえで統合します。

研究者向け：統合解析の考え方

記録数または残留数 ~ トラップ構造 + 実験型 + トラップ構造 × 実験型 + 気温 + 風 + 月齢 + 調査時間 + 地点 + 日付 + 参加者

場所ごとの蛾の多さ、日ごとの条件、参加者ごとの記録の癖を考慮したうえで、トラップ構造の効果を見ます。
