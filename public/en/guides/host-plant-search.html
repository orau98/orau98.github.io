Host plant guide

Find Japanese insects by host plant

When you know the plant but not the insect, start from a host plant page. Each plant page links to the insects recorded from that plant in the source dataset.

How to search

Start with the plant

Use a plant name, genus, or broader group such as cherry, oak, willow, nettle, mugwort, or maple.

Open the plant page

The plant page lists insects recorded as using that plant as a larval host, host plant, or flower-visit plant.

Open candidate insects

Use the linked insect pages to review taxonomy, scientific names, host plants, season, and notes.

Check sources

For research or identification work, verify the original Japanese references listed on each profile page.

Some English plant routes use scientific names generated from the Japanese source data. If a link changes, use the English plant index.

Scope

This site compiles insect-plant relationship records from field guides and literature. Some records may reflect older taxonomic treatments or older plant-name usage.

For scientific, educational, or high-stakes use, check the source references on the profile pages before relying on a record.
